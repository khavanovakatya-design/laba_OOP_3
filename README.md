# 💎 Ювелирный интернет-магазин «Бриллиант»

Добро пожаловать в репозиторий проекта **«Бриллиант»**. Это полноценный интернет-магазин ювелирных украшений, разработанный на фреймворке Django.

## 🌟 Что умеет наш сайт

* **Главная страница:** Современный дизайн с премиальными шрифтами, анимациями и удобной навигацией.
* **Каталог товаров:** Удобная сетка украшений с фильтрацией и сортировкой.
* **Карточка товара:** Подробное описание, фото, выбор количества и добавление в корзину.
* **Корзина:** Подсчет итоговой суммы и изменение количества товаров.
* **Оформление заказа:** Удобная форма доставки, которая сохраняет заказы в базу данных.
* **Личный кабинет:** 
  * Загрузка аватарки профиля.
  * Редактирование личных данных.
  * История всех совершенных заказов.
* **Регистрация:** Подтверждение почты (отправка кода на Email) и строгая валидация паролей.

## 🛠️ Стек технологий

* **Backend:** Python, Django
* **Frontend:** HTML, CSS, Bootstrap 5, JavaScript
* **База данных:** SQLite
* **Дополнительно:** Pillow, FontAwesome, Google Fonts.

## 🚀 Как запустить проект

1. Скачайте проект и перейдите в папку с ним.
2. Установите библиотеки: `pip install django pillow django-filter`
3. Примените миграции: `python manage.py migrate`
4. Запустите сервер: `python manage.py runserver`
5. Сайт доступен по адресу: `http://127.0.0.1:8000/`
